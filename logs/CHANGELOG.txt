v1.0.0
======
Release
-------
- First public release of Coil Accelerator Modeler.
- Package metadata, application title, documentation, and version checks now report 1.0.0.

v0.19.3
=======
Changes
-------
- 将项目全局变量 `$proj_initZ` 加入 Optimetrics，固定优化范围为 `0mm...12mm`；缺失时自动创建为 `0mm`，已有合法值保持不变并用作 StartingPoint。
- 同步设置项目变量的 Optimization Min/Max 与 `AcceleratorScreeningOptimization` 内部范围，避免变量表和 Optimization Setup 显示不同的边界。
- 主窗口及独立建模窗口标题统一为 `Coil Accelerator Modeler 0.19.3`。
- 新增 `$proj_initZ` 默认值、已有值保留、范围写入、标题版本同步和 changelog 版本同步回归检查；76 项测试及 AEDT 2024 R2 验证通过。

v0.19.2
=======
Fixes
-----
- 修复 Optimetrics 将 SI 浮点数直接写成无单位属性，导致 `$gap` 等长度变量报错 `Attributes unit type cannot be different from the variable's definition` 的问题。
- Min、Max、MinStep、MaxStep、MinFocus、MaxFocus、Level 和 StartingPoint 现在均换算并写成变量自身的 AEDT 单位，例如 `$gap=2.5mm...7.5mm`、`$C_n=100uF...1200uF`。
- AEDT 验证工具现在实际创建并保存完整 Optimetrics Setup，不再只验证变量和模型/电路生成；73 项测试及 AEDT 2024 R2 实机验证通过。

v0.19.1
=======
Changes
-------
- 调整 v0.19.0 的变量单位策略：AEDT 官方支持的单位原样保留；只有不受支持但可以换算的输入才输出为无单位 SI 数值。
- 几何、位置、电容、电压和电阻变量分别保留 `mm`、`uF`、`V`、`mOhm`/`ohm`；材料表达式使用 AEDT 支持的 `Ohmm` 与 `kg_per_m3`。
- `$capacitor_energy_density`、`$coil_weight_n`、`$capacitor_weight_n` 和 `$device_weight` 保持为有限实数 SI 数值，不再擅自附加或乘以 `1F`、`1kg` 等单位常量。
- 变量验证改为检查单位是否在 AEDT 支持表内，并通过 `si_value` 确认结果为有限实数；复数即使虚部为零也会被拒绝。
- 新增 AEDT 2024 R2 支持单位、材料表达式和 Circuit 直接变量引用验证；72 项测试通过。

v0.19.0
=======
Changes
-------
- All accelerator-generated project variables now store unitless SI real values.
- Geometry, winding, and Circuit component properties attach physical units only where variables are consumed.
- AEDT post-write validation rejects nonempty variable units, non-finite values, and every complex numeric type, including zero imaginary parts.
- Optimetrics bounds and starting points now use unitless SI literals.
- Added an AEDT 2024.2 validation harness and expanded the regression suite to 70 tests.

v0.8.0
======
新增
- 根据 2026-08-08 实机 Maxwell Circuit Component/Pin Survey，将 Winding、Res、DIODE、VPULSE、SW_V4 的 native pin 映射全部固化为 AEDT 实测名称。
- 新增 `rotate_ccw_once()`；专用于 VPULSE 的固定 10 kΩ 并联电阻。
- 将独立诊断工具 `maxwell_circuit_component_pin_survey.pyw` 纳入完整项目包，便于以后重新扫描 AEDT 元件库。

修改
- VPULSE 不再旋转，固定以库默认 0° 竖直放置；实测 n1=正端（上），n2=负端（下）。
- `R_VPULSE_n` 先按 0° 放置，再执行一次 +90° 逆时针 Rotate，使其竖直；旋转后 n2 在上、n1 在下，并与 VPULSE 上/下端分别直接并联。
- 修正 v0.7.x 尚未更新的普通元件旧 pin 名：Winding N1/N2 -> n1/n2；Res 1/2 -> n1/n2；DIODE A/K -> n1/n2。
- 单路 Boost 主开关节点改接 SW_V4.n1（270° 后上端），SW_V4.n2（下端）接地，以匹配固定姿态并缩短导线。
- 单路 Boost 固定接线更新为：Winding.n2 -> R_coil.n1；R_coil.n2 -> DIODE.n1 与 SW.n1；SW.n2 -> GND；DIODE.n2 -> 下一 Winding.n1。
- 10 kΩ 并联电阻移到 VPULSE 侧方、与 VPULSE 同中心高度，减少跨越导线。
- GUI、README、Circuit README 和测试版本号更新为 v0.8.0。
