# Maxwell Linear Accelerator Builder / Maxwell 直线电磁加速器建模器

Version 1.0.0

Windows GUI for building a parameterized Maxwell 2D accelerator model, adding its Optimetrics setup, and generating the matching External Circuit. The program is intended for Ansys AEDT with PyAEDT 0.25.0.

用于建立参数化 Maxwell 2D 直线电磁加速器、添加 Optimetrics，并生成配套 External Circuit 的 Windows 图形程序。程序面向 Ansys AEDT 与 PyAEDT 0.25.0。

加速器流程生成的所有项目变量均不带单位，只保存 SI 单位制下的实数值；米、欧姆米、欧姆、法拉、伏特、千克每立方米、焦耳每千克和千克等物理单位只在几何、绕组或电路元件属性引用变量时附加。写入后程序会读取 AEDT 变量管理器进行校验：变量单位字段非空，或求值结果为复数（即使虚部为 0），都会直接报错。

## 中文使用说明

### 启动与默认值

1. 双击 `maxwell_accelerator_builder.pyw`。
2. 所有输入框、单选框、复选框和拓扑的启动默认值都在 `default.ini` 中。修改后重新启动程序即可生效；也可在 GUI 中点击“打开 default.ini”。
3. 首次启动时，AEDT 工程默认保存在程序所在目录。关闭主窗口时，当前工程路径会自动写入 `default.ini` 的 `last_project_path`，下次启动继续使用。选择已有 `.aedt` 文件不会弹出覆盖确认。

GUI 的中文、英文与数字统一使用 Windows 界面字体“微软雅黑 UI”（`Microsoft YaHei UI`），同时保留 Tk 各类命名字体原有的字号和粗细。

### 建立 Maxwell 2D 模型

1. 打开“Maxwell2D 建模器”标签页，点击“浏览…”选择或填写工程文件。
2. 填写 Design 名称和线圈数量；AEDT 版本留空时自动选择。
3. 选择内径、间距的“统一/独立”方式和 POSon 的“磁阻/感应”模式。需要联合优化材料和重量时，勾选“材料及重量优化”，并填写电容储能密度（默认 `0.85J/g`）。
4. 点击“刷新参数表”创建参数表，填写每级线圈的外径、长度、匝数、填充率、材料和间距；修改后再次点击同一按钮即可校验全部参数并更新 Rdc 预览。
5. 校验通过后点击“建立 Maxwell2D 模型”。
6. 模型成功保存后，再点击“添加 Optimization Setup”。该按钮需要工程中已经存在建模阶段写入的项目变量。

“非图形化模式”在后台运行，并在完成后关闭后台 AEDT；未勾选时会释放 PyAEDT 控制，但保留 AEDT 窗口和工程供用户继续操作。

几何输入中的 `Di`、`Do` 是实际直径。在 Cylindrical About Z 的 XZ 平面中，线圈矩形内边为 `X=Di/2`，径向宽度为 `(Do-Di)/2`，第一级从 `Z=0` 开始。

POSon 公式中，`Cn` 是第 n 级线圈中心，`Fn` 是第 n 级 POSon，`Ln` 是第 n 级线圈长度：

- 两种模式均固定 `F1=$POSon_1=-1000mm`，且第一级不创建、不优化 `u_1`。
- 磁阻：`Fn=C(n-1)+u_n*(Cn-C(n-1))`，`n>=2`。
- 感应：`Fn=Cn-Ln/2+u_n*Ln`，`n>=2`。

Optimization 的基本目标为 Maximize `Moving1.Speed`。磁阻模式 `u_n` 范围为 `-0.2...1.2`，感应模式为 `-0.3...1.6`；线圈长度、外径、匝数和独立 gap 的范围为当前值的 50%...150%；电容范围为 `0.0001...0.0012`（SI 法拉，等价于 `100...1200uF`）。POSdur 的数值范围按米由相邻线圈中心距离确定。`$proj_initZ` 也是长度优化变量，范围固定为 `0...12mm`，缺失时自动创建为 `0mm`。

启用“材料及重量优化”后，每级 `$is_copper_n` 是只取 `0` 或 `1` 的离散优化变量：`0` 代表铝，`1` 代表铜。`$rho_n` 和 `$material_density_n` 均通过 AEDT `if(...)` 跟随该选择，分别使用官方支持的 `Ohmm` 和 `kg_per_m3`；铝取 `2.82e-8Ohmm` / `2700kg_per_m3`，铜取 `1.724e-8Ohmm` / `8960kg_per_m3`。电容比能量没有对应的 AEDT 支持单位，因此按 SI 的 `J/kg` 只写数值（默认 `850`）。Optimization 新增 Minimize `$device_weight` 目标；线圈重量按绕组环形包络体积乘填充率和密度计算，电容重量按 `0.5*C_n*$V^2/储能密度` 计算。

### 生成 External Circuit

1. 打开“External Circuit 生成器”标签页，确认 AEDT 工程和 Maxwell2D Design。
2. 填写新建 Circuit Design 名称，并在“电路拓扑”中选择“单路Boost”、“奇偶Boost”或“薄膜电容+模拟SCR”。
3. 按需设置“同名 Maxwell Circuit Design 已存在时删除并重建”。通常无需修改二极管模型和缺失变量初值；其余 SW_V4、VPULSE、DIODE 与变量参数在 `default.ini` 中设置。
4. 点击“生成并回写 External Circuit”。程序会执行 Create External Circuit，放置全部 `Type=External` 的 Winding，生成元件和连线，导出 `.sph`，再回写 Maxwell。
5. 如需把 Circuit 使用的独立项目变量映射到 Parameter Values，生成完成后点击“同步 Circuit 全局变量 -> Parameter Values”。

单路Boost按相邻级串接；奇偶Boost按 `i -> i+2` 分为奇数、偶数两条链。两种 Boost 拓扑的每级都包含储能电容及 ESR 支路。“薄膜电容+模拟SCR”的每一级都是互不直接连接的独立 `C-Winding-DIODE-SW_V4` 回路，不使用线圈串联电阻、VPULSE 并联电阻、储能电容 ESR 或末级返回电阻。图形模式会优先复用已有 AEDT 会话，因此可以在 Maxwell 2D 建模完成后直接继续生成电路。

Boost 的第一级控制源是 `Type=POS` 的 VPWL，第二级起使用 VPULSE。“薄膜电容+模拟SCR”全部使用 VPULSE，并把 `Pw` 设为 `1e9mm`，模拟触发后持续导通。所有 VPULSE 的第一级 `Td=$POSon_1` 保持不变，第二级起使用 `Td=$POSon_n-$proj_initZ`。程序在缺失时创建 `$proj_initZ=0mm`，已有的、使用 AEDT 支持单位且求值为有限实数的变量不会覆盖。生成器页面及完成提示会提醒：在绘制完动子后，沿Z+方向执行Move操作，Moving Vector为(0,0,$proj_initZ)。点击 Circuit 页面中的红色提醒，会把不带括号的 `0,0,$proj_initZ` 自动复制到剪贴板。组件属性直接引用变量，不再人为附加 `*1meter`、`*1F`、`*1V`、`*1ohm` 或 `*1kg`。

程序错误日志统一保存在 `logs` 文件夹中。

变量单位以 Ansys 官方的 [Circuit and Layout Unit Types](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v251/en/Subsystems/HFSS3DLayout/Content/Circuit/CircuitandLayoutUnitTypes.htm) 及 PyAEDT `AEDT_UNITS` 表为准。官方支持的单位原样保留；不受支持但可换算的输入只写无单位 SI 数值。AEDT 实机校验同时要求每个变量的 `si_value` 是有限实数，复数即使虚部为零也不通过。

程序运行时已禁用 Python 字节码缓存。运行测试请双击根目录的 `run_tests.cmd`；它不会生成 `__pycache__` 或 `.pytest_cache` 文件夹。

## English Instructions

### Start and defaults

1. Double-click `maxwell_accelerator_builder.pyw`.
2. Every initial entry, radio button, check box, and topology selection is controlled by `default.ini`. Restart the program after editing it. You can also click **打开 default.ini** (Open default.ini) in the GUI.
3. On the first launch, the default AEDT project is placed in the program directory. When the main window closes, the current project path is saved as `last_project_path` and restored on the next launch. Selecting an existing `.aedt` file does not show an overwrite confirmation.

The GUI uses the Windows UI font `Microsoft YaHei UI` for Chinese, Latin text, and numbers while preserving the original sizes and weights of Tk's named fonts.

Every project variable generated by the accelerator workflow is unitless and stores a real SI value: meters, ohm-meters, ohms, farads, volts, kilograms per cubic meter, joules per kilogram, or kilograms as appropriate. Physical units are attached only where those variables are consumed by geometry, winding, or circuit-component properties. AEDT validation rejects a generated variable if its unit field is nonempty or its evaluated value is complex, including a complex value with zero imaginary part.

### Build the Maxwell 2D model

1. Open the **Maxwell2D 建模器** (Maxwell2D Builder) tab and click **浏览…** (Browse...) to select or enter the project file.
2. Enter the Design name and coil count. Leave the AEDT version blank for automatic selection.
3. Select common or independent inner diameter and gap values, then choose the reluctance or induction POSon mode. To optimize material and weight together, enable **材料及重量优化** and enter the capacitor energy density (default `0.85J/g`).
4. Click **刷新参数表** (Refresh Parameter Table), enter each coil's outer diameter, length, turns, fill factor, material, and gap, then click the same button again to validate the values and refresh the Rdc preview.
5. After validation succeeds, click **建立 Maxwell2D 模型** (Build Maxwell2D Model).
6. After the model has been saved successfully, click **添加 Optimization Setup** (Add Optimization Setup). The project variables written during model creation must already exist.

**Non-graphical mode** runs in the background and closes the background AEDT session when finished. When it is cleared, PyAEDT control is released while the AEDT window and project remain open.

`Di` and `Do` are actual diameters. In the XZ plane of Cylindrical About Z, the coil rectangle starts at `X=Di/2`, has radial width `(Do-Di)/2`, and the first stage starts at `Z=0`.

In the POSon formulas, `Cn` is the center of coil n, `Fn` is POSon for stage n, and `Ln` is the length of coil n:

- Both modes fix `F1=$POSon_1=-1000mm`; stage 1 neither creates nor optimizes `u_1`.
- Reluctance: `Fn=C(n-1)+u_n*(Cn-C(n-1))` for `n>=2`.
- Induction: `Fn=Cn-Ln/2+u_n*Ln` for `n>=2`.

The base Optimization objective is Maximize `Moving1.Speed`. The `u_n` range is `-0.2...1.2` in reluctance mode and `-0.3...1.6` in induction mode. Coil length, outer diameter, turns, and independent gaps use 50%...150% of their current values; capacitance uses `0.0001...0.0012` (SI farads, equivalent to `100...1200uF`). POSdur bounds are derived from adjacent coil-center spacing in meters. `$proj_initZ` is also a length optimization variable with a fixed `0...12mm` range and is created as `0mm` when missing.

When material and weight optimization is enabled, each `$is_copper_n` is a binary discrete optimization variable: `0` selects aluminum and `1` selects copper. AEDT `if(...)` makes `$rho_n` and `$material_density_n` follow that selection using the officially supported `Ohmm` and `kg_per_m3` units: aluminum uses `2.82e-8Ohmm` / `2700kg_per_m3`, and copper uses `1.724e-8Ohmm` / `8960kg_per_m3`. AEDT has no supported specific-energy unit for this input, so the capacitor energy density is written as a unitless SI `J/kg` number (default `850`). A Minimize `$device_weight` goal is added.

### Generate the External Circuit

1. Open the **External Circuit 生成器** (External Circuit Generator) tab and confirm the AEDT project and Maxwell2D Design.
2. Enter the new Circuit Design name and select **单路Boost** (Single Boost), **奇偶Boost** (Odd/Even Boost), or **薄膜电容+模拟SCR** (Film Capacitor + Simulated SCR) under Circuit Topology.
3. Choose whether an existing Circuit Design with the same name should be deleted and rebuilt. The diode model and missing-variable initial values normally need no changes; configure the remaining SW_V4, VPULSE, DIODE, and variable settings in `default.ini`.
4. Click **生成并回写 External Circuit** (Generate and Write Back External Circuit). The program creates the External Circuit, places every `Type=External` winding, creates and wires the components, exports the `.sph`, and writes it back to Maxwell.
5. To map the independent project variables used by Circuit into Parameter Values, click **同步 Circuit 全局变量 → Parameter Values** (Sync Circuit Global Variables to Parameter Values) after generation.

Single Boost connects adjacent stages. Odd/Even Boost separates the circuit into odd and even chains using `i -> i+2`. Every Boost stage includes a storage capacitor and an ESR branch. Film Capacitor + Simulated SCR creates independent `C-Winding-DIODE-SW_V4` loops with no direct interstage wiring and omits the coil series resistors, VPULSE shunts, capacitor ESR elements, and final return resistors. Graphical mode prefers an existing AEDT session, so circuit generation can follow Maxwell 2D model creation directly.

Boost stage 1 uses a position-controlled VPWL; Boost stages 2 and above use VPULSE. Film Capacitor + Simulated SCR uses VPULSE for every stage with `Pw=1e9mm` to emulate continuous conduction after triggering. Stage 1 keeps `Td=$POSon_1`; stages 2 and above use `Td=$POSon_n-$proj_initZ`. The program creates `$proj_initZ=0mm` only when it is missing and preserves an existing variable that uses a supported AEDT unit and evaluates to a finite real value. The GUI reminder uses `Moving Vector=(0,0,$proj_initZ)`, and clicking it copies `0,0,$proj_initZ` without parentheses. Component properties reference variables directly; the generator no longer adds `*1meter`, `*1F`, `*1V`, `*1ohm`, or `*1kg` constants.

All program error logs are written to the `logs` directory.

Variable units follow Ansys's official [Circuit and Layout Unit Types](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v251/en/Subsystems/HFSS3DLayout/Content/Circuit/CircuitandLayoutUnitTypes.htm) and the PyAEDT `AEDT_UNITS` table. Supported units are preserved; convertible unsupported inputs are emitted as unitless SI numbers. Live AEDT validation also requires every variable `si_value` to be a finite real number; a complex value is rejected even when its imaginary part is zero.

Python bytecode caching is disabled while the application runs. Double-click `run_tests.cmd` to run the tests without creating `__pycache__` or `.pytest_cache` directories.
